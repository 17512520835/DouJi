# 00 · 项目管理架构概述

> **本文档是「斗鸡 DouJi」项目按 PMBOK 知识体系整理后的项目管理框架总览。**

> 阅读顺序：先看本文档了解全局 → 各模块按编号独立阅读 → 配套原始物证见 `../iteration-archive/`。

## 1. 框架选型

本项目采用 **PMBOK 第6版 五大过程组 + 十大知识领域** 的简化适配版本：

| PMBOK 过程组 | 本项目对应模块 | 编号 |
|------------|-------------|------|
| **项目启动** | 项目章程 · 干系人分析 · 需求文档 | 01–02 |
| **项目规划** | WBS · 甘特图时间线 · 风险管理 · 资源矩阵 | 03–06 |
| **项目执行** | 技术实施方案 · 质量保证 | 07–08 |
| **项目监控** | 里程碑跟踪 · 变更管理日志 | 09–10 |
| **项目收尾** | 交付物清单 · 经验教训总结 | 11–12 |

## 2. 项目基准数据

| 指标 | 数值 |
|------|------|
| **项目周期** | V7.0.2 → V7.2.10（12 个公开发布版本） |

| **美术资产** | 111 个文件（V6 完整包 107 + V7.2.8 纯美术 4） |
| **依赖** | 联机服务器 0 npm 依赖；引擎 0 框架依赖 |
| **在线可玩** | GitHub Pages 一键入口（7.7MB 单文件） |
