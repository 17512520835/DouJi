# 10 · 变更管理日志

## 1. 变更控制流程

```
提出变更 ──→ 评估影响面（回归范围/回归耗时/风险）
                │
        ┌───────┼───────┐
        ▼       ▼       ▼
      P0阻断   P1体验   P2架构
        │       │       │
    Hotfix   当前Phase  独立Phase
        │       │       │
        └───────┼───────┘
                ▼
         实现 → 回归 → PASS → 发布 → 写入迭代MD
```
