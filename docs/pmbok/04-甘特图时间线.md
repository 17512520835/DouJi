## 3. 关键路径分析

```
设计审计 ──→ EngineCore(1-4) ──→ ResponseWin ──→ 障碍Vis ──→ 移动Dir ──→ HandOver
                                                                                  ↓
GoldenMaster ←── 长局稳定 ←── 缩域专项 ←── PassiveDraw ←──────────────────────┘
     ↓
   纯美术 ──→ 死手修复 ──→ Online 联机 ──→ 作品集归档
```

**关键路径上最长的链：** EngineCore Phase 1–4 → ResponseWin → 障碍Vis → 移动Dir → HandOver → PassiveDraw → 缩域 → 长局 → GoldenMaster → 纯美术 → 死手 → Online → 归档

**资源瓶颈分析：** 单人到场，每次只能推进一个 Phase。Pipeline 上没有并行节点。唯一可优化的是利用已有回归结果减少重跑时间。
