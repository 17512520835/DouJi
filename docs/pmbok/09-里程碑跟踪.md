## 3. 里程碑趋势

```
早期      中期              后期
M1-M3    M4-M11            M12-M18
 ███     ██████████████    ███████████
 设计    架构封箱+修复       验证封箱+联机+归档
```

早期重点在盘点与架构；中期密集修复+重构；后期收敛到验证+联机+归档。节奏是一次从"探索"到"稳定"到"交付"的完整 PM 闭环。
