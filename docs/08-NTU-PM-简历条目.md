## DouJi — End-to-End Digital Boardgame Development & Deployment

**2025年12月 – 2026年08月**  
**Role: Project Lead (Solo Developer & PM)**

- Led the full lifecycle delivery of a browser-based 2-player turn-based digital boardgame across 12 public releases and 6 delivery phases, from design audit to online multiplayer deployment.
- Structured the project using a tailored PMBOK framework covering all five process groups: initiated with a project charter and stakeholder analysis; planned via Work Breakdown Structure (WBS) defining 18 work packages across 6 top-level deliverables; monitored through 18 milestones achieving a 94.4% completion rate.
- Established a three-tier quality assurance pipeline comprising 24 automated regression test scripts, 22 machine-readable JSON verification reports, and a cross-version Golden Master comparison (163 command steps, 12/12 scenarios consistent, 0 unexplained deviations) to enforce regression-free releases.
- Orchestrated the architectural migration of a monolithic 7.7MB single-file codebase into a deterministic engine core (386KB production bundle) with encapsulated Observation boundaries, reducing rule coupling and enabling independent UI and core development—completed across 4 incremental architecture phases with per-phase verification gates.
- Delivered an authoritative-server online multiplayer platform (Node.js, 0 npm dependencies, self-built WebSocket protocol) supporting room-code-based real-time 2-player matches, deployed via GitHub Pages with zero installation required for end users.
- Produced and archived 27 original iteration documents (each following "symptom → root cause → fix → verification" structure), 22 JSON validation reports, and 111 art asset files, establishing a fully traceable evidence chain for project decisions and quality outcomes.
- Maintained transparent AI-assisted development boundaries: explicitly documented AI involvement scope (code implementation details and tooling generation) versus independent PM decisions (version planning, bug diagnosis, architecture selection, and quality gate design) via a standalone AI Boundary Disclosure document.
