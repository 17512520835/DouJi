# 07 · 部署与发行

> **本作品集怎么让别人访问 / 试玩 / 自己跑起来。**

## 1. GitHub Pages（推荐 · 公网可玩）

### 启用步骤（5 分钟）

1. 把本仓库 push 到你的 GitHub（默认分支为 `main`）
2. 仓库页面 → **Settings** → 左侧 **Pages**
3. Source 选 **Deploy from a branch**
4. Branch 选 `main`，Folder 选 `/ (root)`
5. 点 **Save**
6. 等 1–2 分钟，GitHub 会给你一个链接：
   ```
   https://<你的用户名>.github.io/DouJi/
   ```
7. 把这个链接写进 README.md 的「在线试玩」节

### 注意事项

- 根目录的 `index.html` 就是入口（7.7 MB 单文件版，整包内联）
- 不需要任何构建步骤——GitHub Pages 直接托管静态文件
- 第一次访问可能要等 1–2 分钟编译，之后缓存生效

## 2. itch.io（独立游戏平台 · 推荐作为作品集第二分发点）

### 上架步骤（15 分钟）

1. 注册 itch.io 账号（如有则登录）
2. 右上角 **Create new project**
3. Title 填 `斗鸡 DouJi — Digital Boardgame`
4. Kind of project 选 **HTML**
5. 勾选 **This file will be played in the browser**
6. 在 **Uploads** 里：
   - 上传本仓库根目录的 `index.html`（重命名为 `index.html`——它就是入口）
   - 上传 `assets/` 整个目录（保持目录结构）
7. **Viewport dimensions** 选 **Match the game's dimensions**
8. **Orientation** 任意（桌面浏览器比例）
9. 写一段游戏简介 + 截图（可选）
10. 发布

### 优点

- 独立游戏社区认可度高
- 留学申请材料里放 itch.io 链接比纯 GitHub 更"作品集感"
- 支持嵌入 YouTube / B 站视频作为演示

## 3. 网盘备用方案

### 适用场景

- GitHub Pages 被墙时（如某些地区）
- 想直接发"开袋即玩"链接给非技术朋友
- itch.io 上架流程不想做

### 操作

1. 把本仓库的 `index.html`（7.7 MB）和 `assets/` 目录打包成 `douji-portable.zip`（约 8 MB）
2. 上传到你常用的网盘（百度网盘 / 阿里云盘 / OneDrive / Google Drive）
3. 生成分享链接
4. 把链接写进 README.md 或简历

### 用户体验

对方下载 → 解压 → 双击 `index.html` → 浏览器自动打开游戏 → 即玩。

## 4. 联机版部署（在线对战）

如果你想让朋友远程联机（不仅限局域网），需要额外部署一个 Node.js 联机服务器。

### 选项 A：家里电脑（最便宜 · 适合临时）

```bash
# 1. 主机电脑运行
cd src
./启动联机服务器.bat   # Windows
# 或
chmod +x 启动联机服务器.sh && ./启动联机服务器.sh   # macOS / Linux
```

主机访问 `http://localhost:8787` 创建房间，朋友通过内网穿透工具（如 ChmlFrp、NATAPP）连接。

### 选项 B：公网云主机（稳定 · 适合长期）

最低成本推荐：**Railway 免费档**（$5/月额度，足够支持小型联机）

```bash
# 1. 把仓库 push 到 GitHub
# 2. Railway.app → New Project → Deploy from GitHub repo
# 3. 选本仓库
# 4. 启动命令：node src/online-server.js
# 5. 端口：8787
# 6. Railway 自动给一个 https://xxx.up.railway.app 域名
```

朋友直接访问这个域名即可。

### 选项 C：内网穿透（零成本 · 主机需开机）

参考 `docs/06-AI辅助边界声明.md` 提到的 ChmlFrp 方案——用隧道把公网地址转发到本地 8787。本机要全程开机。

### 选项 D：腾讯云轻量 / 阿里云 ECS（国内低延迟 · 长期稳定）

最便宜的配置（约 ¥40–60/月）就足够。注意需要打开防火墙 8787 端口。

## 5. 数据持久化说明

**本作品集的所有版本均无数据持久化：**

- **本地版：** 每次双击 `index.html` 重新开始
- **联机版：** 房间在服务器重启后即丢失（设计如此，详见 `docs/02-需求规划.md` § 4）

如果将来要做持久化（排行榜 / 回放分享），需要：
1. 给服务器加 SQLite / Redis
2. 给客户端加登录态（GitHub OAuth 即可）
3. 这是 Phase 2 的工作，不在本作品集范围

## 6. 多渠道分发优先级建议

如果你时间有限，按这个优先级做：

1. **GitHub Pages** ← **先做**（5 分钟，公网可玩，对留学申请材料直接加分）
2. **简历 / 文书** ← **同步做**（把 GitHub Pages 链接写进简历项目经历）
3. **itch.io** ← **其次**（独立游戏社区认这个，留学申请能加分）
4. **网盘备用** ← **最后**（实在找不到其他方案时再做）
