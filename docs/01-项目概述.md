# 01 · 项目概述

> **5 分钟读懂这个项目在做什么、为什么这样做、做到哪一步。**

## 1. 一句话定义

**《斗鸡 / 一技之长》** 是一款双人对战的回合制数字桌游。本仓库是它在 **V7.2.10 Online Phase 1** 节点上的**作品集快照**，用于留学申请中展示项目统筹 / 需求规划 / 进度管控 / 迭代优化能力。

## 2. 项目范围

| 维度 | 范围 |
|------|------|
| **玩法** | 2 人回合制卡牌 + 地图移动 + 战技 |
| **角色数** | 9 个（V7.1.1 起最终封箱） |
| **核心机制** | 出牌 / 移动 / 攻击 / 追击 / 反击 / 挣脱 / PendingChoice |
| **联机** | Phase 1（2 人 P2P 房间，权威服务器架构） |
| **平台** | 浏览器（Chrome / Edge / Firefox 现代版本） |
| **数据持久化** | 无（每次重开是新对局；联机服务器重启即丢房间） |

**明确不在范围内：**
- 商业发行、付费系统、内购
- 跨平台原生客户端（iOS / Android / Windows）
- 多人房间（>2 人）、观战、回放分享、积分系统

## 3. 项目阶段

| 阶段 | 时间 | 重点 | 产出物 |
|------|------|------|--------|
| **设计审计** | V7.0.2 | 把模糊玩法拆解为可验证规则 | 设计审计报告 |
| **架构封箱** | V7.1.1 Phase 1–4 | 把游戏核心抽离为确定性的纯函数模块 | Engine Core Phase 4 架构契约 |
| **机制修复** | V7.1.3 / V7.2.1–V7.2.4 | 真实对局暴露的 bug 修复 | 4 个修复说明 + 4 份验证报告 |
| **地图重构** | V7.2.5–V7.2.6 | 缩域 / 长局稳定性 | Phase 4 缩域专项 + Phase 5 长局 |
| **最终封箱** | V7.2.7 Phase 6 | 跨版本 Golden Master 比对 | Observable Golden Master 验证报告 |
| **联机交付** | V7.2.10 Phase 1 | 浏览器 P2P 联机 | 权威服务器 + WebSocket 协议 |

## 4. 项目目标（立项初心）

| 目标 | 是否达成 |
|------|---------|
| 9 角色完整可玩 | ✅（V7.1.1 起） |
| 同一 seed 跨版本 100% 一致 | ✅（Phase 6 Golden Master） |
| 12 局长局无崩溃 / 无超时 | ✅（V7.2.6 长局稳定性） |
| 隐藏信息（手牌 / 牌堆）正确隔离 | ✅（V7.2.10 候选交付） |
| 2 人浏览器联机 | ✅（V7.2.10 Online Phase 1） |
| 全部交付可对外展示 | ✅（本仓库） |
