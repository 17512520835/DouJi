# V7.1.1 Engine Core Phase 4 — Core Boundary & Deterministic Closure

这是 Deterministic Core 架构阶段的最终封箱版。Phase 4 不再扩大规则迁移范围，只完成边界强制、验证器修正、事件增量协议和 Fuzz/Replay 封箱。

## 1. 生产 API 封口

生产引擎 `engine.v714.core.bundle.js` 不再创建 `global.V6`。浏览器仅得到冻结的 `window.GameEngine` Facade：

- `version`
- `gameplayVersion`
- `createGame(config)`
- `replay(replay)`
- `createAI(...)`
- `catalog`

`GameEngineCore` 的真实 GameState 存在模块私有 `WeakMap` 中；Core 实例不再有可读取/可写入的 `_state`，也不提供 `getInternalStateForTests()`。

生产 UI 使用 `frontend.engine-adapter.v714.js`。该适配器仍保持旧前端所需的调用形状，但所有状态修改最终只调用 Core `dispatch(command)`；它不会获得内部规则函数引用。

测试需要细粒度规则函数时使用 `engine.v714.core.debug.bundle.js`。Debug build 明确只供测试/诊断，不被正式 HTML 引用。

## 2. Observation 边界

`getObservationForSide(side)` 输出 UI 可渲染的受控快照：

- 己方手牌可见；
- 对手手牌只保留数量/hidden 占位；
- 双方牌堆顺序均隐藏；
- RNG state、ID counters、失败动作集合等引擎控制字段不外泄；
- 私有 PendingChoice 只对所属 side 暴露详情；
- UI/AI 均通过 Observation 获取状态，不直接持有 GameState。

## 3. Event delta + sequence

每个领域事件新增稳定的递增 `sequence`，并保留原 `eventId`。

`dispatch(command)` 只返回本 command 新产生的事件：
`events: [delta only]`

同时返回：
`eventSequence: { from, to } | null`

完整展开 Event Ledger 仍留在内部状态中，继续作为展开历史事实源。command-local event sink 是模块私有临时收集器，不存入 GameState，因此不形成第二套历史账本。

## 4. Forbidden mirror 验证器修正

不再使用“源码里 forbidden 字符串出现即失败”的错误定义。

Phase 4 验证采用两层：

1. 运行态 `assertCoreInvariants()`：任何 forbidden key 回到 `mechanics` 立即报错。
2. 静态语义扫描：允许字段名存在于 invariant 禁止名单/测试中，但禁止 `mechanics.xxx`、`mechanics['xxx']`、对象业务字段 `xxx:` 等实际业务上下文。

## 5. Fuzz 发现并修复的封箱 Bug

随机合法 command sequence 首轮封箱发现：

`拉封骑士 / 骑枪总冲(lance_charge)` 在 PRE_ATTACK 直接把 phase 切到 `CHASE_WINDOW`，但没有先建立 expansion，触发：
`ENGINE_INVARIANT: CHASE_WINDOW 必须存在 expansion`

Phase 4 修复为：绝技需要开启追击时，先 `ensureExpansion(draft, side)`，再进入 `CHASE_WINDOW`。该修复不改变绝技数值、文本、美术或旧版本文件。

## 6. 停止条件

Phase 4 后，Deterministic Core 架构阶段按以下条件封箱：

- Production UI cannot mutate rules except through Core commands
- Hidden information only exits through Observation
- Expansion history has one authoritative Ledger
- Replay(config + seed + commands) reproduces digest
- Random legal sequences preserve invariants
- Golden Masters remain preserved

后续引擎修改按正常 bugfix/feature 流程处理，不再继续 Phase 5/Phase 6 式架构迁移。
