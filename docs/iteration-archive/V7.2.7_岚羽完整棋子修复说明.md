# V7.2.7 岚羽完整棋子修复说明

## 问题原因
岚羽并不是被 CSS 或 Canvas 裁掉了下半身。原交付包中 `HERO.lanyu` 的
`selection / sidebar / token / portrait` 四份透明美术本身就只有上半身：
透明像素占据了画布上半部，下半身素材不存在，所以所有调用这些资源的界面都会显示成“半身棋子”。

## 本次修复
- 不改引擎规则、角色数值、地图、移动、追击或响应逻辑。
- 直接复用交付包内已有的岚羽全身卡图【掠林飞矛】作为全身视觉来源。
- 重新生成 `selection / sidebar / token / portrait` 四种尺寸。
- 使用柔和透明渐隐，避免地图棋子出现生硬的矩形卡图边缘。
- 其余八名角色美术未改动。

## 影响范围
仅岚羽视觉资源；玩法逻辑不受影响。
