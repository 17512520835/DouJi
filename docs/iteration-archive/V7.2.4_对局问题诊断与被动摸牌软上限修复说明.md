# V7.2.4 对局问题诊断与修复说明

本次回放结束时仍处于 PRE_ATTACK，已经到第43大回合、第4节；囚徒013手牌14张、牌库仅剩1张。日志中【抑制崩坏】累计触发27次；中央资源点连续占领出现 streak 3→7，并在3连占后持续摸牌。

这里不是“第6张以后Core判非法”，也不是【抑制崩坏】在同一大回合无限触发。真正问题是：上一版V7.2.3只解决了超量手牌的UI可用性，但整备型被动资源仍会在已有5张以上时继续摸牌。于是【抑制崩坏】、中央资源点和主动摸牌叠加后，长局会持续制造无成本手牌膨胀。

本轮不设置硬手牌上限，而把5张定义为“整备型摸牌的软目标”：
- 【抑制崩坏】仍每大回合最多1次，仍回2生命；只有手牌少于5张时再摸1。
- 中央资源点的气/能奖励完全不变；3连占以上的摸牌只补到5张。
- 日志的 draw 改为记录实际摸牌数量，并增加 drawBlocked 方便回放诊断。
- 【剧痛咆哮】等主动卡牌/技能摸牌仍可超过5张。
- V7.2.3 的左右浏览、滚轮横向浏览、键盘操作和滚动位置恢复全部保留。

这样修的是“被动资源膨胀来源”，不是粗暴截断玩家主动构筑出来的爆发手牌。
