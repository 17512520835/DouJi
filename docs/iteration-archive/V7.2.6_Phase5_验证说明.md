### 1. 多 Seed 完整 AI 长局
新增 `v7.2.6_phase5_long_ai_stability.js`。

本次实跑 12 个确定性 Seed，覆盖九角色的自对局与交叉对局，全部自然结束：
- 12/12 completed
- 0 COMMAND_REJECTED
- 0 Event 重复
- 0 Snapshot 污染
- 12/12 replay final digest 一致
- ExpansionLedger 单展开峰值 31
- ResponseWindow / PendingChoice 作为单活跃事务，观测峰值深度 1
- Core 为同步 dispatch 架构，不存在持久 Action Queue 对象，因此以合法动作集合峰值与 dispatch 拒绝/卡死作为队列稳定性观测。

内存采用 Node `--expose-gc` 的局后强制 GC 采样。本轮 post-GC 从 6,216,576 bytes 到 7,067,080 bytes；
后半程在约 6.8–7.3 MB 区间波动，没有观察到随对局数线性、无界增长的证据。
这只能表述为“本样本未观察到泄漏”，不能替代更长时间的 profiler soak。
