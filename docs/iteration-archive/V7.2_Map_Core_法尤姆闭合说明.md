# V7.2 Map Core / 法尤姆闭合候选

正式入口：`斗鸡_缩域争鸣_V7.2_Map_Core_法尤姆修复版.html`

本版以 V7.1.3 ResponseWindow / 地图稳定版为唯一基线，不改九角色平衡和伤害数值。

## 法尤姆兼容性闭合
- 【太阳算式】统一为“查看并可重排牌堆顶 3 张”。
- PendingChoice 由 Core 持有；拥有者 Observation 才能读取三张牌，对手只得到 `private:true` 占位。
- UI 新增真实“观看牌堆顶 3 张”排序窗口，可上移/下移并显式 SubmitChoice。
- 提交协议使用稳定 `instanceId`，支持连续牌顶事务与快照恢复。
- AI 仍只接收红acted Observation，不获得对手私有牌序。

## V7.2 Map Phase 1
- GameState 新增权威 `mapState`：格子状态、缩域状态、角色占位、资源点和补给点目标。
- UI 地图的 `danger / zone` 改为读取 Observation 中的 `MapState`，不再以静态地图常量裁定缩域显示。
- 主动移动/强制位移产生 `POSITION_CHANGED`、`DISTANCE_CHANGED`、`APPROACHED / MOVED_AWAY / LATERAL_MOVE` 领域事件。
- 击退标记为 `forced:true`；缩域后的非法占位由 Core 按“最近合法格 -> 标签稳定排序”确定性迁移。
- Core 提供 `queryMapState()` 与现有 `queryReachableMovePaths()`，UI 只消费查询结果。

## 冻结项
- 不修改角色伤害、费用和卡牌重做内容。
- V7.1.3 ResponseWindow、Buff 状态栏、Observation session token 修复全部继承。
- 本包标记为 Map Phase 1 候选；更复杂的据点交互/多地图数据迁移继续在 V7.2 后续 Map Phase 完成。
