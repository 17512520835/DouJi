# V7.2.9 死手与可用牌修复说明

## 对局记录结论

记录末尾白夜处于 `PRE_ATTACK`，能量 5、气 5，但手牌为：

- 终成白夜：追击牌
- 缩颈防身：反击牌
- 幼生惊逃：反击牌
- 破壳跃升：追击牌
- 湖畔追啄：追击牌

这些牌在行动阶段都不是合法的主动出牌，因此“有能量却没办法用牌”不是费用问题，而是手牌时点全部不匹配。

## 根因

旧版展开结束的“整备换手”判定只在“没有反击牌且没有起手攻击牌”时触发。
因此只要手里存在任意反击牌，就会阻止换手，即便整手都只有追击/反击牌，主动回合仍然会卡死。

同时旧判定也会漏算移动、增益、资源、控制、恢复、状态等正常主动牌，存在误换手风险。

## 修复

改为判断“手里是否至少有一张 PRE_ATTACK 主动入口牌”：

- 起手攻击 / active 攻击
- 移动
- 增益
- 资源
- 控制
- 恢复
- 状态

若一张都没有，且本大回合尚未使用整备换手，则自动弃掉整手并摸等量牌。

反击牌与追击牌不再阻止死手换手。

## 蓝色格说明

本地图有两类蓝色水域：

- 浅水 `shallow_water`：可进入；进入后本次移动立即结束。
- 深水 `deep_water`：不可进入。

另外在“选择移动落点”模式中，UI 会用蓝色描边表示“后退”落点、青色表示“前进/侧移”。这个蓝色是移动关系提示，不是禁行提示。

所以白夜进入浅水或点击蓝色“后退”目标均属于现有地图机制；深水仍然禁止进入。

## 验证

新增 `v7.2.9_dead_hand_regression.js`：
1. 白夜“3追击+2反击”的复现场景会正确触发整备换手。
2. 手牌存在移动牌时不会被误判为死手。

并已通过现有 Browser Entry Static Smoke、Observable Golden Master、核心机制闭合与九角色完整行为回归；原有批准例外/旧版本号警告保持不变。
