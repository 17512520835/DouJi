# V7.2.5 Phase4 缩域专项改动说明

本阶段针对 Phase2 最大风险点“缩域”做专项加固，不调整角色数值。

## 核心修复
- `shrinkZone` 增加按 `section + side` 的迁移幂等令牌：同一缩域阶段每名存活角色最多强制迁移一次。
- 已死亡角色不参与缩域强制迁移，避免死亡后被清理逻辑再次移动。
- 强制迁移仍唯一经过 `MovementResolver.resolve(... SHRINK_RELOCATE ...)`，不新增第二套位移实现。
- `map_relocation` 日志增加 `section`，便于回归定位重复迁移。

## 专项覆盖
1. 正常缩域。
2. 两名角色同时处于非法站位。
3. 资源点被置于危险区时，Objective 元数据不被缩域覆盖。
4. 危险区伤害造成死亡后，不进入迁移循环。
5. 缩域强制迁移后再发生击退，不触发第二次缩域迁移。
6. 缩域后再次位移，不重复迁移。
7. AI 侧角色缩域后落点必须为可行走且未封锁格。
8. 连续 50 次重复调用同一缩域阶段，迁移次数仍保持每侧 1 次。

## 验证结论
专项回归：10/10 PASS。
