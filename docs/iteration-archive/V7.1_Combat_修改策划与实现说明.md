# V7.1 Combat 修改策划与实现说明

## 一、承接 V7.0 Core 的设计结论

V7.0 Core 已冻结战斗底座：主行动与展开主动权分离、每击响应、反攻转移、结构化条件、事件账本、牌序事务、状态快照与统一合法性入口。V7.1 不再改写这套时序，而是在同一规则入口上完成角色内容层迁移。

本轮遵循五条原则：

1. 九角色各自只保留一条明确的“条件生态”，避免通用加伤、抽牌、回能套餐。
2. 技能负责稳定建立角色条件，普通牌负责路线选择，绝技负责收尾或改变攻防节奏。
3. AI 不能只按即时伤害选牌，必须识别角色标签、资源保留、位移、反击与终结路线。
4. Combo Solver 使用公开手牌、资源、距离和展开状态，不读取对手隐藏信息，也不修改真实状态。
5. V7.0.2/V7.0.3 的状态机、隐藏信息、响应窗口和状态快照回归必须继续通过。

## 二、九角色重做方向

- 洛基：命中确认与拳击压制。试探起手，第二击确认，身体打击与墙角收尾。
- 赤羽战魂：击退距离与围猎路线。击退、撞墙、倒地、僵直形成空间链。
- 拉封骑士：精准防反与荣誉夺权。少击高质量，保留资源等待反击与夺权。
- 囚徒013：受伤、痛觉与失控。自伤/失血建立风险资源，再由追击和处刑兑现。
- 白夜：成长阶段与牌面变形。仅让少量核心牌承担阶段变化，避免全牌库三套效果。
- 岚羽：飞行、落点与俯冲。起飞、空中追击、选择落点、俯冲收尾。
- 游影·麻步：接近、远离、侧移节奏。自主位移与不移动选择共同构成连击条件。
- 玄医·乌骨：治疗转攻与药势循环。实际治疗、反击准备和追针共同构成攻防转换。
- 法尤姆·命织者：牌序、预言与命线。牌序事务、循环、远程命线与命运收尾分工。

## 三、技能与绝技

每名角色的至少一个技能和一个绝技新增 V7.1 战术标签，标签被 AI 与测试共用。技能标签覆盖 chain_setup、counter_setup、move_synergy、heal、resource、deck_order 等用途；绝技标签覆盖 finisher、status_payoff、fly_payoff、fate_payoff、auto_end 等用途。

本轮保持现有技能/绝技执行 ID 与结算入口，避免破坏 V7.0 Core 的合法性、响应和状态快照契约。

## 四、AI

角色 AI 在原六维评分上加入 V7.1 角色画像加权：连击、铺垫、移动、反击、保留、治疗、资源等权重按角色差异调整。签名牌和终结牌获得额外识别，不再把零伤技能统一视为低价值动作。

## 五、Combo Solver

新增 `v71ComboSolver(state, side, options)`：

- 束搜索深度 1—6、宽度 1—24；
- 读取公开手牌、能量、距离、当前展开计数和已公开状态；
- 支持字符串条件、all/any/not 复合条件；
- 计算追击减费、白夜觉醒减费、桥接位移、射程、状态转换和角色标签收益；
- 输出路线、剩余能量、终态条件与搜索分数；
- 纯读取，不改变牌库、手牌或战斗状态。

AI 起手评估已接入 Solver：最佳路线的起手牌获得完整路线分，其他起手牌保留旧前瞻的折算分。
