# V7.2 Map Phase 2 — 旧 board 规则依赖迁出与 Golden Master 封箱

本轮继续以 V7.1.3 ResponseWindow / 地图稳定版为行为基线，不调整九角色数值与卡牌平衡。

- `MapState` 升级为 `7.2-mapstate-2`，加入坐标索引、邻接边、地形、可通行性、缩域状态、目标与占位。
