# V7.2.1 地图障碍与不可穿越边可视化

本次仅调整前端地图表达，不改变 V7.2 MovementResolver、MapState、寻路成本或合法性规则。

## 改动

- 所有 `walkable:false` / `obstacle:true` 的障碍格改为明显抬高的 3D 台体表现。
- 岩石障碍使用两字标记 **「岩障」**；其他不可进入障碍格使用 **「禁行」**。
- 所有 `passable:false` 的相邻边绘制为粗暗色“立边/断层”，附顶部亮边与下缘阴影，使“视觉相邻但不能直接穿越”在地图上直接可读。
- 原有高地、草地、灌木、泥地、水域、危险区、封锁区颜色逻辑保留。
- 移动详情补充说明：粗立边不可直接跨越，需要寻找坡道或其他合法路径。

## 规则边界

此次改动没有新增或修改移动规则；视觉层完全读取现有 `walkable / obstacle / passable` 事实源，因此不会制造 UI 与 Core 两套判定。
