# V7.2.8 纯美术优化说明

## 定位结论

岚羽主界面“只显示半截身子”的直接原因已确认：

- HTML 的 `HERO.lanyu.selection` 内嵌图像本身就是错误的半身/圆形视觉源，不是 `object-fit`、Mask、锚点或容器高度导致的裁切。
- 同一组 `sidebar / token / portrait` 也沿用了同源错误形象，因此本次一并做身份一致性修复。
- 角色选择页背景已经内嵌了 V6 美术包的 `hero_select.jpg`，但 CSS 写成 `url('assets/data:image/...')`，浏览器会把 Data URI 当成相对路径，导致该背景无法正常加载。

## 本次仅美术层修改

1. 从当前 V6 美术包真实存在的 `01_风格基准/九角色身份基准.png` 提取岚羽完整角色形象，制作并替换：
   - selection：完整主界面/选人立绘
   - sidebar：侧栏显示
   - token：地图棋子
   - portrait：头像
2. 修正角色选择页背景的纯 CSS Data URI 前缀，使内嵌的 `06_UI/screens/hero_select.jpg` 正常显示。
3. 使用 `06_UI/buttons/` 中 secondary / primary / danger / action 的 default、hover、pressed、disabled 资源统一按钮视觉。
4. 仅增加选中角色卡片阴影和立绘居中表现，不改变任何控件 ID、点击事件、状态机或交互流程。
