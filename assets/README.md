# Assets · 美术资产说明

## 现有资产

本仓库美术资产仅 4 张 WebP，集中在 `art/美术优化资源/`：

| 文件 | 用途 | 大小 |
|------|------|------|
| `岚羽_portrait.webp` | 主视觉 / README 头部 / 选角界面 | ~18 KB |
| `岚羽_sidebar.webp` | 侧边栏头像 | ~25 KB |
| `岚羽_selection.webp` | 选角高亮态 | ~45 KB |
| `岚羽_token.webp` | 棋盘 token | ~22 KB |

**说明：** 美术资产是 V7.2.8 纯美术优化阶段的产物。**不修改任何游戏逻辑**，只改视觉。`engine.v721.core.bundle.js` 中的图片引用与这些 WebP 文件一一对应。

## 资产使用规则

1. **不外泄：** 岚羽角色立绘仅供本项目使用，不二次分发到他处
2. **不修改：** 任何美术修改请提交 PR 并附对比图
3. **格式：** 统一 `.webp`，避免 `.png`、`.jpg` 等格式膨胀体积
4. **命名：** 中文角色名 + 用途（如 `岚羽_portrait.webp`）
